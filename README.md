# Tic Tac Toe - Java (LLD)

A console-based Tic Tac Toe game implemented in Java using Object-Oriented Design principles.

## Features

- Two-player game
- Configurable board size
- Strategy Pattern for winning logic
- Object-Oriented Design
- SOLID Principles
- Exception handling for invalid moves

## Design Patterns Used

- Strategy Pattern

## Entities

- Game
- Board
- Player
- Cell
- Symbol
- WinningStrategy

## How to Run

Compile

```bash
javac *.java
```

Run

```bash
java Main
```
